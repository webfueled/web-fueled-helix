# Web Fueled Helix

A scroll-driven Three.js interaction by Web Fueled.

The project combines a deformed card helix, counter-moving guide lines, editorial typography, a staggered 3×2 card transition, and light/dark scene blending.

## Project files

- `index.html` — page structure
- `styles.css` — layout and visual styling
- `main.js` — Three.js scene, geometry, animation, and scroll behavior
- `assets/` — card artwork
- `AI_SOURCE.md` — project entry point for AI-assisted development
- `AI_INSTRUCTIONS.md` — implementation constraints
- `VALIDATION.md` — expected behavior checklist

## Development notes

The interaction has been visually calibrated as a complete composition. When extending or adapting it, preserve the motion system unless the change specifically requires altering animation behavior.
